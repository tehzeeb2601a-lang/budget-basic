BUDGETBASICS – NextGen BudgetBee

1. PROJECT NAME
BudgetBasics

2. PROJECT THEME
NextGen BudgetBee

3. CATEGORY
Web Innovation Unleashed

4. PROJECT DESCRIPTION
BudgetBasics is an educational website designed to help students understand basic financial concepts such as income, expenses, budgeting, savings, needs and wants.

5. TECHNOLOGIES USED
- HTML5
- CSS3
- JavaScript

6. MAIN FEATURES
- Budgeting Basics
- Needs vs Wants
- 50-30-20 Budget Rule
- Savings Goals
- Expense Planner
- Money Mistakes
- Budget Infographics
- Search
- BudgetBee Assistant
- About Section
- Feedback Form
- Contact Section
- Sitemap
- Date and Time
- Visitor Counter
- Responsive Design

7. HOW TO RUN
1. Open the BudgetBasics project folder.
2. Open index.html in a web browser.
3. The website will run directly in the browser.

8. BACKEND
This project does not use PHP, MySQL or a backend server.
The project is implemented as a frontend website using HTML, CSS and JavaScript.

9. RESPONSIVE DESIGN
The website is designed to work on desktop, tablet and mobile screen sizes.

10. IMPORTANT NOTE
The BudgetBee Assistant provides educational information. It is not professional financial advice.
